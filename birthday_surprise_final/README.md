# Birthday Surprise — Recipient Ready ❤️

This version has the supplied memories and birthday song embedded in the website.

## What is included
- 6 supplied photos in the exact upload order
- Supplied birthday song
- Intro → balloons → cake → roses → letter → final reveal → memories
- No photo upload prompt for the recipient
- No audio upload prompt for the recipient
- Music starts after the first interaction because mobile browsers block autoplay before interaction

## Run
Open `index.html` in Chrome.

## Share
For a public link, upload the entire project folder to a static website host. Do not send only `index.html`; the `assets` folder is required.

## Note
The six photos supplied in this chat are included. Photos that were visibly sideways were rotated for the final presentation.
